Simple Flow

આ component નો flow આવો છે:

Page load → getUsers() → users API માંથી આવે
Edit click → old data copy થાય → editing data change થાય
Save click → changes compare થાય → request pending બને
Approve → new data API માં update થાય
Reject → old data API માં પાછું update થાય
Delete → user API માંથી delete થાય

Important beginner point

આ code માં direct edit save નથી થતું. પહેલા change request બને છે. પછી approve કરવાથી જ actual API update થાય છે. આ company projects માં useful હોય છે, જ્યાં admin approval required હોય.
